Site GitHub

Contact manager application is a full-stack project built using the MERN stack (MongoDB, Express, React, Node.js) with robust features like secure JWT authentication, bcrypt password hashing, and seamless CRUD operations for managing contacts. The application also includes an innovative OCR feature using Tesseract.js, allowing users to upload images containing contact details and extract the data automatically. Tour India Guide

Site GitHub

TourIndia Guide is a Web application built using HTML, CSS, JavaScript, and jQuery that allows users to input a set of cities and calculates the shortest path covering all destinations and reaches the source station at end. It provides detailed distance, duration, and timings between cities and cost estimation. Integrated with Rapid API's Distance and Hotel API to retrive distance between every pair of cities and hotel details of every city.
